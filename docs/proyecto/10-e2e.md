# E2E con Playwright

- **Cubre:** el solicitante crea una requisición de $20,500 con 2 renglones y la envía; `aprobador` y `aprobador2` firman; el Outbox crea la orden y el aviso; Compras los ve en `/compras/ordenes` y `/compras/avisos` (un contexto de navegador por usuario).
- **Local** (Docker, .NET 10, Node 24; puertos 5432, 5103 y 4200 libres):
  `docker compose up -d db && cd web && npm ci && cd ../tests/e2e && npm ci && npx playwright install chromium`
  `export E2E_CLAVE="$(openssl rand -base64 18)-Aa1" && npx playwright test`
- `levantar.sh` (lo lanza Playwright) recrea la base `requi_e2e`, aplica el migrador con los usuarios de demo, siembra un catálogo solo para la prueba (`semilla.sql`), arranca la API (:5103, Outbox activo) y `ng serve` (:4200). Al terminar los apaga; `docker compose down` apaga la base.
- **Tiempo:** unos 30 s con todo instalado. La clave nunca se guarda: en el CI se genera en el job `e2e`.
